# Scotto26 (SK46)

The Scotto26 is a 26-key split 3x4 keyboard that uses combos for the inner column keys on a normal 3x5 layout.

You can read more about the components and how to build it [here](https://scottokeebs.com/blogs/keyboards/scotto26-handwired-keyboard).
